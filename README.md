# Customer Shopping Trends - Exploratory Data Analysis (EDA)

## Overview
This repository contains an exploratory data analysis (EDA) conducted on the Customer Shopping Trends dataset. The primary objective is to investigate consumer purchasing behaviors, demographic distributions, and key factors influencing customer engagement.

## Key Insights and Analysis Topics
The analysis focuses on several core aspects of the dataset:
- Customer Distribution by Gender: Examining demographic representation across the customer base.
- Purchase Categories: Identifying the most frequently purchased product categories.
- Average Spending by Gender: Comparing average expenditure levels (`Purchase Amount (USD)`) across gender segments.
- Shipping Methods vs. Ratings: Evaluating customer review ratings across different shipping options.
- Subscription Status and Purchase Frequency: Assessing whether active subscribers demonstrate higher shopping frequency.

## Tech Stack
- Python
- Pandas: Data manipulation, summary statistics, and missing value checks
- Matplotlib & Seaborn: Statistical data visualization

## Project Structure
- `custome-data-analysis.ipynb`: Jupyter notebook containing the full data exploration workflow and visualizations.
- `shopping_trends_updated.csv`: The primary dataset utilized for the analysis.
- `README.md`: Project documentation and overview.

## Getting Started
To replicate or run the notebook locally:

1. Clone this repository:
   git clone https://github.com/yavuzselimcakir/customer-shopping-trends-analysis.git

2. Install the necessary Python packages:
   pip install pandas matplotlib seaborn

3. Launch Jupyter Notebook or Google Colab and run `custome-data-analysis.ipynb`.
